1. 在线安装

sudo apt update

sudo apt install 软件名

2. 本地 .deb 安装包

使用 apt 安装（推荐，可自动补全依赖）：

```
sudo apt install ./filename.deb
```

使用 dpkg 安装（传统方式，若提示缺少依赖需执行 sudo apt -f install）：
```
sudo dpkg -i filename.deb
```

3. Flatpak / Snap 通用包

适用于需要最新版本软件或独立沙盒环境的场景。
```
# 先安装 flatpak 支持
sudo apt install flatpak

# 安装软件（以 Flathub 为例）

flatpak install flathub 软件ID
```

4. 源码编译安装

适用于没有现成安装包、需要自定义编译选项或开发测试的场景。
```
# 1. 安装基础编译工具
sudo apt install build-essential

# 2. 解压并进入源码目录
tar -xvf source-code.tar.gz
cd source-code

# 3. 配置、编译与安装
./configure
make
sudo make install
```

5. 便携式脚本 / 二进制文件

部分软件提供直接运行的 .sh 安装脚本、独立 binary，或无需安装的 AppImage 文件。

```
chmod +x install.sh
sudo ./install.sh
```
AppImage（无需安装，直接运行）：
```
chmod +x software.AppImage
./software.AppImage
```

在 Debian 系统中使用 Flatpak 管理软件（查找、安装、运行、更新、卸载）的详细操作指南：

准备工作（只需配置一次）
```

# 1. 安装 Flatpak 工具
sudo apt update && sudo apt install flatpak

# 2. 添加官方 Flathub 软件源（全球最大的 Flatpak 镜像库）
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

# 3. （推荐）配置国内镜像源（以中科大源为例，加速下载）
flatpak remote-modify flathub --url=https://mirrors.ustc.edu.cn/flathub

# 重启系统或重新登录以生效环境配置
```

查找软件
```
flatpak search 软件名
```

列出已安装的 Flatpak 软件
```
flatpak list --app
```

安装软件

按 Application ID 安装（最标准方式）：
```
flatpak install flathub 软件ID

示例：安装 VS Code

flatpak install flathub com.visualstudio.code

```


从本地 .flatpakref 或 .flatpak 文件安装：

```
flatpak install ./filepath.flatpakref
```



运行软件
```
flatpak run 软件ID

示例：flatpak run com.visualstudio.code
```

更新软件

更新所有已安装的 Flatpak 软件：

```
flatpak update
```
更新指定软件：
```
flatpak uninstall 软件ID

示例：flatpak uninstall com.visualstudio.code
```

彻底卸载（同时清除该软件的本地数据/配置文件）：
```
flatpak uninstall --delete-data 软件ID
```
清理无用依赖（卸载软件后留下的孤立运行时环境）：
```
flatpak uninstall --unused
```
